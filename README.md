# Control de Trabajo

Página de una sola pieza (`index.html`) para llevar el registro diario del puesto:
ventas por categoría, gastos, apartado de material, ganancia neta, inventario de
plantillas, calculadora y resumen semanal.

## Cómo se usa

Abre `index.html` en el navegador. No necesita internet ni instalar nada.

## Importante sobre los datos

- Los registros se guardan **solo en el navegador de cada dispositivo** (localStorage).
  No se suben a GitHub ni a ningún servidor.
- Si cambias de celular, de navegador o de dirección web, empiezas en blanco.
  Antes de cambiar, usa el botón **"Respaldar / restaurar datos"** → **Descargar respaldo**,
  y en la página nueva usa **Cargar archivo de respaldo** → **Restaurar**.
- Este repositorio contiene solo el código de la página, nunca datos del negocio.
